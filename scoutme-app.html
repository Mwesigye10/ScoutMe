🟢 Ingen agent
Klubber kontakter dig direkte. Du håndterer selv eventuelle kontrakter – evt. med hjælp fra forældre, venner eller advokat.
🤝 Agent mulig efter kontakt
Du er åben for agent-involvering, men kun hvis en klub vil skrive kontrakt. Klubber ved hvad de går ind til.
👔 Har agent (Pro)
Din agent er tilknyttet din profil og synlig for klubber. Kontakt går via agenten. Kræver at din agent har Pro-konto.
Hvorfor er dette vigtigt?
Klubber kan filtrere på agentstatus. Ærlighed skaber bedre matches og undgår misforståelser.
✅ Næsten klar!
Din klub-profil sendes til verifikation. Vi kontakter jer inden for 2–3 hverdage.
